# CSYM019 Starter Repository

This repository is used as starter code/structure for the CSYM019 coursework.

## Required weekly progress (assessed)
You must demonstrate ongoing development work throughout the project.

Minimum expectations:
- **At least 3 meaningful commits per week**
- Commit messages must describe the change (avoid “update”, “final”, “fix”).
- Update `/docs/progress.md` weekly with:
  - What you completed this week
  - What you will do next week
  - Any blockers/issues
  - Screenshots/evidence where applicable (store images in `/assets/`)

**Late bulk uploads (e.g., one large commit near the deadline) will be treated as poor progress evidence and may be penalised and marked as Auto Generated.**

## Folder structure
- `/src` – application source code
- `/sql` – database schema / seed scripts
- `/docs` – weekly progress log + notes
- `/assets` – screenshots and evidence

## Environment setup
- Copy `.env.example` to `.env` and fill in your local credentials.
- **Do not commit `.env`** (it is ignored by `.gitignore`).
